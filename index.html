🛡️ HTTP security header guide

A quick reference for headers you may encounter during an authorized web assessment.

Strict-Transport-Security (HSTS): encourages HTTPS connections. Content-Security-Policy (CSP): restricts permitted content sources. X-Content-Type-Options: nosniff: helps prevent MIME-type sniffing. X-Frame-Options: helps control framing by other sites. Referrer-Policy: controls referrer information sent by browsers. Permissions-Policy: controls access to selected browser features.

A missing header is not automatically proof of an exploitable vulnerability. Review the application's context.
